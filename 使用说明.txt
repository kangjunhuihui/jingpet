============================================
  鲸鲸聊天助手 —— 使用说明
============================================

【怎么开始用】
1. 双击 鲸鲸.exe（Windows 10/11）
2. 首次打开会弹出登录窗口，需要填写 API Key：
   - 没有的话去 https://platform.deepseek.com 注册后创建
   - 密钥长这样：sk-xxxxxxxxxxxxxxxx
3. 点「测试连接」可以验证密钥有没有填对
4. 点「开始聊天」就进入和鲸鲸的聊天界面啦

【怎么聊天】
- 输入框打字，点「发送」或按 Ctrl+Enter
- 想让它联网搜索时，输入「搜一下」「帮我查查」等词开头，比如：
  「搜一下 今天上海天气」
- 点 📎 按钮选图片，或者直接把图片拖进窗口，可以问图片内容
- 生成过程中点红色 ⏹ 可以停止

【常见问题】
Q: 搜索没反应 / 提示找不到浏览器？
A: 搜索功能需要电脑装了 Edge 浏览器（Win10/11 自带）。
   驱动已内置在程序里，不需要联网下载；如果提示"找不到 Edge"，
   说明这台电脑没装 Edge，装一个就能搜了。

Q: 提示 API Key 错误？
A: 检查密钥是否复制完整（sk- 开头，中间无空格）。

Q: 杀毒软件报毒？
A: PyInstaller 打包的单文件程序偶尔会被误报，
   添加信任即可；介意的话就不要用了。

Q: 聊天记录存在哪？
A: 存在你的用户目录下，只有你自己能看到。

【隐私说明】
- API Key 不会保存在任何文件里，每次打开都要重新输入
- 聊天记录只保存在本机
